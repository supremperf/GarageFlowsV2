# Checklist d'onboarding pilote

> **MODÈLE — NON SIGNÉ.** À personnaliser par garage.

## Avant l'installation
- [ ] Accord pilote + RGPD signés (`DATA_PROCESSING_CHECKLIST.md`).
- [ ] Poste Windows conforme (10/11 x64) OU accès web/PWA.
- [ ] Coordonnées du référent garage.

## Installation
- [ ] Installer l'application (installateur Windows) ou ouvrir la PWA.
- [ ] Activer la licence pilote.
- [ ] Créer/paramétrer le garage (identité, TVA, mentions, IBAN, préfixes).
- [ ] (Marque blanche pilote éventuelle : `../WHITE_LABEL_GUIDE.md`).

## Données initiales
- [ ] Import des clients/véhicules/pièces (aujourd'hui : saisie ou procédure
      manuelle — l'assistant CSV/XLSX est un chantier, voir `KNOWN_LIMITATIONS.md`).
- [ ] Vérifier quelques dossiers créés (client → véhicule → OR → devis → facture).

## Prise en main (jour 1)
- [ ] Créer un rendez-vous, un ordre de réparation, ajouter pièces/main-d'œuvre.
- [ ] Générer un devis, le convertir en facture, vérifier HT/TVA/TTC.
- [ ] Générer une facture électronique (UBL/CII) + dépôt sandbox + statut.
- [ ] Faire une sauvegarde locale.

## Formation (jour 1–3)
- [ ] Parcours planning / atelier / stock / rentabilité.
- [ ] Points d'attention (numérotation, immuabilité facture émise).

## Suivi
- [ ] Baseline de mesure enregistrée (semaine 1).
- [ ] Canal de support ouvert (`PILOT_SUPPORT_PLAYBOOK.md`).
